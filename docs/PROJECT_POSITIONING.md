# 项目定位与目标

## 项目是什么

`ECS_Service_Manage` 是一个面向运维场景的 Web 管理面板，用于在 Ubuntu ECS 上统一完成以下工作：

- `systemd` 服务管理（启动、停止、重启、状态）
- Docker 容器管理（列表、启停、重启、删除、日志）
- 对外暴露面扫描（公开端口、反向代理 URL）
- 代理规则配置（为容器定义域名/路径并应用到 Nginx）

目标是优先通过 **域名+路径** 暴露服务，减少直接端口访问。

## 项目为什么存在

- 降低远程运维门槛：不用频繁 SSH 手敲命令
- 统一操作入口：系统服务、容器、代理在同一面板内联动
- 面向移动场景：手机可直接访问并执行常用操作
- 形成可持续协作：人类与 Agent 都有统一上下文和规范

## 主要使用者

- 项目维护者（人类）
- 持续开发 Agent（Cursor Agent）
- 临时运维协作者（按权限使用面板）

## 成功标准

- 面板可稳定访问并完成核心操作
- 每次发版路径统一（本机构建 -> ACR -> ECS 拉起）
- 代理配置可持续演进，避免零散手改 Nginx
- Agent 在无上下文情况下也能快速接手开发
